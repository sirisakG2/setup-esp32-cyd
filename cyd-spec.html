Live test

Plug the board in, press Connect board, and pick the port named usbserial in the popup. The checks below fill in by themselves. Works in Chrome, Edge or Opera (Safari and Firefox don't support this).

Gotchas we already hit

Real problems from this board's setup, each written up as a GitHub issue.

Board not detected: a charge-only cable lights the LED but has no data wires. Swap the cable first. Issue #1

Touch never responds: touch uses its own pins (25, 32, 39, 33, 36), not the display's. Issue #2

Touch lands in the wrong place: measure the four corners and map them yourself instead of guessing rotations. Issue #3

Flash is nearly full with Bluetooth: the BLE keyboard plus graphics filled 94% of the default partition, so the project uses huge_app.csv.
